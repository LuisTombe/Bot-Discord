# 🥷 Bot World X — Sistema de Administración Open World & RPG (Shindo Life 2)

[![Deploy on Bot-Hosting](https://bot-hosting.net/assets/deploy-badge.svg)](https://bot-hosting.net/deploy?source=github&repo=LuisTombe%2FBot-Discord&visibility=public&name=Bot+World+X)

Bot oficial de Discord para la administración del modo **Open World & RPG** en Shindo Life 2.
- **Punto de entrada:** `main.py` (o `bot.py`)
- **Python:** `3.12+`
- **Base de datos:** SQLite 3 con WAL (`data/worldx-v2.sqlite3` — *excluida del repositorio público para proteger todos los registros de los jugadores*).
